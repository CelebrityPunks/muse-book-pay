Book-and-Pay Privacy Policy

Last updated: September 20, 2026
Contact: bob.haddad.33@gmail.com
Operator: Independent developer (sole proprietor), operating as Book-and-Pay.

What this service does

Book-and-Pay is a Muse connector API for booking services and creating deposit intents. Muse calls our API on your behalf when you ask to check availability, get a quote, hold a slot, cancel, or start a deposit.

Data we process

  • Booking details you provide: service ID, date/slot, name, quote ID
  • Payment intent metadata: booking ID, amount, currency (processed via Stripe Link; we never see full card numbers)
  • Technical logs: timestamps, request IDs, error logs, retained 30 days

What we don't do

  • No sale of personal data. No ads. No profiling.
  • No access to your Gmail, Calendar, or Muse conversations — Muse only sends the fields needed for the booking call.
  • No charge is made in beta unless you complete Stripe Link checkout explicitly.

Legal basis / consent

We process data to perform the booking you requested via Muse. Connecting the service and approving the action is your consent. You can withdraw by disconnecting the connector and emailing us to delete records.

Retention

Bookings kept 12 months for receipts/disputes, then deleted. Logs 30 days. Email requests for deletion: bob.haddad.33@gmail.com, handled within 30 days.

Revocation

Revoke your API token or disconnect in Muse Settings > Connectors at any time. Revoked tokens stop working immediately.

Subprocessors

Railway (hosting), Stripe (payments via Link), GitHub (spec hosting). Data stored in the US.

Security

HTTPS only, Bearer tokens via Muse Secure Credentials Store, idempotent writes, least-privilege scopes (reads vs writes), input validation.

Children

Not intended for under 13. Do not use for children's bookings.

Changes

We will update this page and bump the date for material changes.
